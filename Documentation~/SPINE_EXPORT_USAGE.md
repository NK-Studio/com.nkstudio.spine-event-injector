# 내보내기 PoC 사용법 — `spine_export.py`

Spine 프로그램 없이 `.spine` 프로젝트를 런타임용 파일로 내보낸다.

- 스켈레톤 JSON(`.json`), 스켈레톤 바이너리(`.skel`)
- 이미지 묶기(`.atlas` + `.png`)
- 대상 버전: Spine 4.0 ~ 4.3

원리와 검증 결과는 [`SPINE_EXPORT_SPEC.md`](SPINE_EXPORT_SPEC.md)에 있다.

## 1. 준비

- Python 3.9 이상. 표준 라이브러리만 쓴다(설치할 패키지 없음).
- `export_poc/`와 `poc/`(파일 해석기와 스키마)가 함께 있어야 한다.
- 내보내기 자체에는 Spine이 필요 없다. `check_against_spine.py`로 Spine 결과와 비교할 때만 Spine이 필요하다.

명령은 저장소 루트에서 실행한다고 가정한다.

## 2. 기본 사용

```bash
# JSON과 .skel을 같이 만든다
python3 export_poc/spine_export.py 입력.spine 출력폴더 --version 4.2.43

# 바이너리와 atlas
python3 export_poc/spine_export.py 입력.spine 출력폴더 --version 4.2.43 --format binary --atlas --images 이미지폴더
```

| 옵션 | 뜻 | 기본 |
|---|---|---|
| `--format json\|binary\|both` | 만들 스켈레톤 형식 | `both` |
| `--version 4.2.43` | 내보낼 런타임 버전(4.0.xx ~ 4.3.xx) | 프로젝트 포맷 버전 |
| `--name 이름` | 출력 파일 이름(스켈레톤이 하나일 때만) | 스켈레톤 이름 |
| `--skeleton 이름` | 이 스켈레톤만 내보낸다 | 프로젝트의 모든 스켈레톤 |
| `--atlas` | 이미지를 atlas로 묶는다 | 안 묶음 |
| `--images 폴더` | 이미지 폴더 | 프로젝트에 적힌 경로(`.spine` 기준) |
| `--nonessential` / `--no-nonessential` | 비필수 데이터(색·경로 등) 포함 여부 | JSON은 포함, 바이너리는 제외(Spine CLI 기본과 같음) |
| `--preset anc` | 팀 export 설정을 한 번에 켠다(아래 표). 따로 준 옵션이 우선 | 없음 |
| `--clean` / `--no-clean` | Spine의 "애니메이션 정리"와 같이 불필요한 키를 지움 | 끔 |
| `--no-pma` / `--pma` | 알파 프리멀티플라이 끄기/켜기 | 켬 |
| `--bleed` / `--no-bleed` | 투명 픽셀 RGB를 주변색으로 채움(PMA를 끌 때만 적용) | 끔 |
| `--alias` / `--no-alias` | 같은 이미지를 atlas의 한 자리에 합침 | 끔 |
| `--max-size 2048` | atlas 페이지 최대 폭·높이. 넘치면 페이지를 나눔 | 4096 |
| `--skel-ext`, `--atlas-ext` | 출력 확장자 | `.skel`, `.atlas` |

### 팀 export 설정 (`--preset anc`)

```bash
python3 export_poc/spine_export.py 입력.spine 출력폴더 --version 4.2.43 --preset anc
```

Spine 내보내기 창의 설정 중 다음을 맞춘다: Binary, 필수적이지 않은 데이터, 애니메이션 정리, `.skel.bytes`, `.atlas.txt`, PMA 끔, 블리드, 에일리어스, 최대 2048. 공백 제거·회전·알파 임계값 3·패딩 2·가장자리 패딩·Linear는 원래 같다.

여러 트랙을 겹쳐 재생하는 프로젝트는 애니메이션 정리를 켠 결과와 끈 결과의 포즈가 다를 수 있다. Spine에서 정리를 켜고 내보내는 프로젝트라면 `--clean`도 켜야 같은 결과가 된다.

**`--version`은 꼭 주는 편이 좋다.** 프로젝트에 적힌 포맷은 저장한 Spine 버전과 다를 수 있다. 예를 들어 Spine 4.2.22로 저장한 파일의 포맷이 `4.0.07`일 수 있는데, 지정하지 않으면 4.0 형식으로 나온다. 게임 런타임 버전에 맞춘다. 낮은 버전으로 내보낼 수도 있다(`4.2` 프로젝트 → `--version 4.1.24`).

스켈레톤이 2개 이상이면 스켈레톤마다 `스켈레톤이름.json`·`.skel`·`.atlas`를 만든다. 하나만 내보내려면 `--skeleton 이름`을 준다(`--name`은 스켈레톤이 하나일 때만 쓴다). 첨부의 Export를 끈 항목과 그 키는 Spine처럼 빠진다.

## 3. 지원 범위와 아직 안 되는 것

공식 예제 프로젝트 전부를 Spine CLI 결과와 비교했다(결과는 [`SPINE_EXPORT_SPEC.md`](SPINE_EXPORT_SPEC.md) §6).

**JSON과 `.skel`로 내보낼 수 있는 기능**: 뼈, 슬롯, 스킨(폴더 포함), IK·변형·경로·물리·슬라이더(4.3) 제약, 이미지·메시·링크드 메시·바운딩 박스·클리핑·경로 첨부, 시퀀스, 드로우 오더, 이벤트.

이런 경우는 **파일을 만들지 않고 이유를 말한 뒤 멈춘다**.

- 포맷 `4.1.04-beta`, `4.2.56-beta`로 저장한 프로젝트 (스켈레톤 앞쪽의 편집기 상태를 아직 읽지 못한다)
- 그 밖에 스키마 목록에 없는 포맷 버전
- 물리 타임라인 중 wind 외의 종류, 슬라이더 타임라인 중 mix 외의 종류, translatex·translatey 외의 분리 타임라인 (표본이 없어 번호를 확인하지 못했다)
- 슬라이더 제약을 4.2 이하로, 물리 제약을 4.1 이하로 내보내기

슬라이더를 4.2 이하로, 물리를 4.1 이하로, 시퀀스를 4.0으로 내보내는 `.skel`도 만들지 않는다. `--format both`면 가능한 형식만 만들고 알려 주며, `--format binary`면 오류로 멈춘다.

슬라이더 제약의 일부 저장 필드(태그 5·6·7·8·14·15)는 뜻을 몰라 JSON에 쓰지 않는다. 예제 1개로만 확인한 기능이다.

## 4. Spine 결과와 다른 점

| 항목 | 차이 | 게임에서의 영향 |
|---|---|---|
| 스켈레톤 해시 | 계산법을 몰라 본문 SHA-1 앞 8바이트로 채운다 | 없음(런타임은 쓰지 않는다) |
| 4.0~4.2 가중치 메시의 삼각형 순서 | 같은 삼각형, 순서만 다르다 | 렌더링 동일 |
| 4.3 JSON 숫자 끝자리 | 프로젝트당 수십~1천여 개 값이 마지막 자리에서 다르다(0.5333334 / 0.5333333) | 무시할 수준 |
| `.skel` 가중치 메시의 정점 값 | 일부 float 끝자리가 다르고(재계산 오차), 첨부 순서 등으로 바이트가 다를 수 있다 | 정점 차이 0.00001 수준 |
| 편집기로 다시 저장한 파일의 바이너리 | 일부 정점 값이 float 마지막 비트에서 다르다 | 무시할 수준 |
| atlas 페이지 배치 | 영역 이름·크기·오프셋·픽셀은 같고 페이지 안 위치와 페이지 크기는 다르다 | 없음 |

atlas의 나머지 설정(여백 2, 투명 부분 잘라내기, 회전 허용)은 고정이고, 프로젝트별 설정을 읽지는 않는다. 팀 설정은 `--preset anc`로 맞춘다.

`--preset anc` 결과와 Spine 4.3.26 export의 차이(`cat.spine`): 페이지 안 배치가 다르고, 메시 이미지는 투명 테두리를 자르지 않으며(보이는 차이는 Spine이 잘라낸 134픽셀), 완전 투명 픽셀의 RGB가 1,321개 다르다. 에일리어스는 Spine이 합친 73개 묶음을 모두 합치고, 보이는 픽셀과 오프셋이 같은 묶음을 14개 더 합친다.

## 5. Spine 결과와 비교하기

```bash
python3 export_poc/check_against_spine.py
python3 export_poc/check_against_spine.py --versions 4.1.24,4.3.26 --samples sb
```

`research/versions/` 표본을 그 버전의 Spine CLI로 내보내 우리 결과와 비교한다. Spine 설치와 Professional 라이선스, 해당 버전 업데이트가 있어야 한다(다른 위치면 환경변수 `SPINE_BIN`). 해시와 삼각형 순서는 제외하고 비교하며, 마지막에 `결과: 12/12 통과`처럼 요약이 나온다. 하나라도 다르면 종료 코드가 1이다.
